## 🎯 What Is This?

Tantu C Framework is a free, open-source tool that lets you build websites using the C programming language. Think of it like a LEGO set for the web—you snap together pre-built pieces (modules) to create your own site. Whether you're a student learning to code, a hobbyist tinkering with IoT devices, or someone who just wants a simple website, Tantu makes it possible without needing to learn complex web languages.

The name "Tantu" means "weave" in several languages, and that's exactly what it does—it weaves together different parts of the internet (from tiny chips in devices to cloud servers) into one cohesive web experience.

## ✨ Key Features

### 🧩 Modular Design
Every part of Tantu is a module. You can pick and choose what you need for your project. Need a blog? Add the blog module. Need a photo gallery? Add that module. It's that simple.

### 🌐 Works From Chip to Cloud
This isn't just for big computers. Tantu is designed to work on tiny embedded devices (like Raspberry Pi or Arduino) all the way up to massive cloud servers. Your code can run anywhere.

### 📝 Markdown Support
Write your content in simple Markdown (like you're writing an email), and Tantu automatically converts it to beautiful web pages. No HTML knowledge needed.

### 🔍 SEO Friendly
Search engines will love your website. Tantu automatically generates clean, optimized code that helps your site rank higher in Google search results.

### ⚡ WebAssembly Ready
Tantu can compile your C code to WebAssembly, which means it runs in the browser at near-native speed. This opens up possibilities for complex web applications.

### 🏗️ Static Site Generator
Generate complete websites in seconds. Tantu builds all your pages in advance, making them load incredibly fast.

## 📚 Quick Tutorial: Your First Website

Let's build a simple website in just a few minutes.

### 🗂️ Step 1: Create a Project Folder

Create a new folder on your desktop called "my-first-site". Open it.

### 📝 Step 2: Write Some Content

Inside that folder, create a new text file. Rename it to `index.md` (make sure it's not `index.md.txt`). Open it with Notepad and type:

```
# Welcome to My First Site!
This is so easy. I'm building a website with C!
```

Save the file.

### 🏃 Step 3: Build Your Site

Now, go back to the Tantu folder and run the application again. This time, type:

```
tantu build my-first-site
```

Press Enter. Watch as Tantu weaves your Markdown into a complete website.

### 🌟 Step 4: See Your Creation

Open the `my-first-site` folder again. You'll see a new `index.html` file. Double-click it, and your website opens in your browser! You just built a website with C.

## 🛠️ Customizing Your Site

### 🎨 Themes
Tantu comes with several built-in themes. To change your site's look, edit the `config.tantu` file in your project folder. Look for the line that says `theme = "default"` and change it to `theme = "dark"` or `theme = "ocean"`.

### ➕ Adding Pages
Create new `.md` files in your project folder. Each one becomes a page. For example, create `about.md` with your about content, and you'll get an `about.html` page.

### 🔗 Linking Pages
To link between pages in your Markdown, just write the filename. For example, `[Learn about me](about.md)`.

Tantu was built with security in mind. Since it generates static pages, there's no database to hack, no server-side code to exploit. This makes Tantu websites naturally more secure than dynamic sites.

Performance-wise, static sites load incredibly fast. No waiting for server responses—the browser just displays the pre-built pages instantly.
